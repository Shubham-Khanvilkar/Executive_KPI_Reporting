# Data Dictionary

Synthetic wealth-management-style operating dataset used for SQL, Python and Power BI analysis.

| Field | Description |
|---|---|
| month | Reporting month |
| business_unit | Business unit grouping |
| aum | Assets under management |
| inflows | New asset inflows |
| outflows | Asset outflows |
| revenue | Revenue for the period |
| opex | Operating expense |
| clients | Client population |
| retained_clients | Retained clients |
| advisors | Advisor headcount |
| target_nna | NNA target |

Derived metrics include NNA = inflows - outflows, NNA attainment, net flow rate, operating margin and retention rate.

All values are synthetic and intended for portfolio practice only.
