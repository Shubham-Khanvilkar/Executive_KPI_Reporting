# Power BI Executive Dashboard

This folder contains the Power BI implementation specification for the Executive KPI Reporting project.

## Dashboard pages

### 1. Executive Overview
- Total AUM
- NNA
- NNA target attainment
- Net flow rate
- Revenue
- Operating margin
- Client retention
- Monthly NNA trend

### 2. Business Unit Performance
- AUM by business unit
- NNA contribution
- Target attainment
- Revenue and operating margin
- Business-unit ranking

### 3. Flow & Retention Analysis
- Inflows vs outflows
- NNA trend
- Client retention trend
- Advisor productivity
- Exception/underperformance indicators

## Data model

The dashboard is designed around a monthly KPI fact table with dimensions for Month and Business Unit. Measures are calculated in DAX rather than hard-coded in the source data.

## Recommended Power BI workflow

1. Load `data/monthly_kpis.csv` into Power BI.
2. Set Month as a date field and financial metrics as numeric fields.
3. Create the DAX measures in `dax_measures.dax`.
4. Build the three report pages using the layout above.
5. Add slicers for Month and Business Unit.
6. Configure conditional formatting for target attainment and KPI variance.
7. Publish the report to Power BI Service after validating totals against the SQL and Python outputs.

## Validation approach

Power BI totals should reconcile to the SQL queries in `sql/executive_kpi_queries.sql` and the Python output generated by `src/executive_kpi.py`.

> Note: The `.pbix` binary is intentionally not stored in this repository. The source data, SQL, Python transformation logic and DAX measure definitions are version controlled here.
